Open where it builds trust. Private where it builds advantage.

Vortex Dispatch uses an open-core model for agent-orchestrated software engineering. VXD is our public, Apache-2.0 AI coding-agent orchestration project. The commercial software factory, production intelligence and customer-specific operating systems remain private.

What is VXD?

VXD is an open-source AI coding-agent orchestrator maintained by Vortex Dispatch. It coordinates software work across planning, isolated git worktrees, implementation, review, QA and delivery workflows. Developers can inspect, run and extend VXD independently.

What remains private?

Vortex Dispatch keeps commercial production policies, proprietary prompts, routing intelligence, optimisation heuristics, cross-project learning, customer governance, deployment controls and accumulated operational data outside the public VXD repository.

Why use an open-core model?

Open source gives engineering teams something concrete to evaluate. They can inspect the architecture and run VXD themselves. The private layer protects the production knowledge and systems that compound through commercial software delivery.

How does VXD relate to Vortex Dispatch?

VXD is the public orchestration project. Vortex Dispatch is the commercial software engineering company. We use agent-orchestrated engineering systems, including public and private technology, to build and deliver production software for clients. Customers buy software outcomes and engineering capability; they do not need to adopt the same internal factory systems we use.
